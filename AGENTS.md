# Contributor agent guide

This repository contains the official TypeScript SDK for the Saturation `/v1`
API. Keep changes small and verify the published package shape.

## Source boundaries

- `openapi/openapi.yaml` is the committed API contract snapshot.
- `src/generated/` is generated by `@hey-api/openapi-ts`. Do not edit it by hand.
- `src/mutate/write-surface.gen.ts`, `write-surface.interface.gen.ts`, and
  `write-surface.bridge.gen.ts` are generated from the SDK operation inventory.
- `src/resources/`, `src/saturation.ts`, `src/http.ts`, and `src/errors.ts` are
  the hand-written client layer.

When the API contract changes, update the snapshot from
`https://docs.saturation.io/openapi.yaml`, run `pnpm generate`, and commit the
snapshot with every generated change. The generator fails when its reviewed
write allowlist references an operation that the contract removed.

## Required checks

Run these before handing off a change:

```console
pnpm install --frozen-lockfile
pnpm generate:check
pnpm typecheck
pnpm test
pnpm build
npm pack --dry-run
```

Add a regression test for behavior changes. Type-level behavior belongs in
`src/__typetests__`.

## Public contract

Keep the README examples aligned with exported methods and the alpha install
tag. Do not document internal monorepo paths or unpublished endpoints. Use the
published OpenAPI contract for exact request and response shapes.

Do not change the package version, license, or release workflow unless the task
explicitly includes a release decision.
